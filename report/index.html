1 Tổng Quan Hệ Thống & Kiến Trúc

SDO (Smart Detection & Optimization) là hệ thống nhận diện đèn giao thông end-to-end sử dụng kiến trúc Microservices bao gồm 3 thành phần chính:

Thành phần Công nghệ Chức năng Port
Worker Python / FastAPI Suy luận YOLO, phân tích HSV, nhận diện OCR 8000
Orchestrator TypeScript / NestJS Điều phối luồng ảnh, quản lý Redis cache 3000
Frontend TypeScript / Next.js + React Hiển thị ảnh với khung detection overlay 4200

2 Huấn Luyện Mô Hình YOLO-P2 Custom

Lý do cần mô hình custom

YOLOv8n pretrained trên COCO chỉ có class traffic light (class_id=9) nhưng không phân biệt được trạng thái (đỏ/vàng/xanh) và không phát hiện được vật thể rất nhỏ như bóng đèn đơn lẻ trong cụm đèn. Do đó, chúng tôi huấn luyện một mô hình YOLO-P2 chuyên biệt.

YOLOv8-P2 là gì?

📐 Kiến trúc P2 — Thêm Head ở Stride 4

YOLOv8 tiêu chuẩn có 3 detection head ở stride 8 (P3), 16 (P4), 32 (P5). Biến thể P2 thêm một head bổ sung ở stride 4, tương đương feature map lớn gấp 4 lần P3. Điều này cho phép phát hiện các vật thể cực nhỏ (tiny objects) như bóng đèn LED, chữ số đếm ngược trên đèn giao thông.

Thông tin huấn luyện

Tham sốGiá trị

Class SmallObjectDetector

Model YOLO-P2 được wrap trong class SmallObjectDetector với các tính năng:

  • Adaptive Letterbox: Scale ảnh giữ tỷ lệ về 640×640, pad pixel (114,114,114)
  • Coordinate Remap: Chuyển tọa độ từ không gian padded về tọa độ crop gốc bằng nghịch đảo scale và offset
  • Device Selection: Tự động chọn CUDA → MPS → CPU
class SmallObjectDetector:
    def predict(self, crop, conf_threshold=0.10):
        # 1. Letterbox 640×640
        padded, scale, (pad_x, pad_y) = self.adaptive_letterbox(crop)
        # 2. YOLO inference
        results = self.model.predict(source=padded, conf=conf_threshold)
        # 3. Remap coordinates: (xyxy - pad) / scale
        for box in results:
            lx = (xyxy[0] - pad_x) / scale  # → original crop coords

3 Pipeline Phát Hiện Đèn Giao Thông

Pipeline detection gồm 4 tầng xử lý tuần tự trong hàm execute_spatial_recursion():

Tầng 1 — Phát hiện cụm đèn (Base YOLO)

Chạy YOLOv8n trên toàn bộ ảnh gốc với:

  • imgsz = 1280 — độ phân giải cao giúp phát hiện đèn nhỏ/xa
  • conf_threshold = 0.10 — ngưỡng thấp để không bỏ sót
  • Chỉ lấy class_id == 9 (traffic light)
  • Bỏ qua box nhỏ hơn 20 × 15 px

Tầng 2 — Weighted Box Fusion (WBF)

Merge các box chồng chéo bằng thuật toán WBF với IoU threshold = 0.30. Mỗi cluster box được fuse thành 1 detection duy nhất với tọa độ trung bình có trọng số theo confidence.

Tầng 3 — Phân tích chi tiết từng cụm đèn

Với mỗi cụm đèn đã phát hiện:

  1. Crop vùng đèn từ ảnh gốc
  2. Upscale 4× bằng Lanczos4 — nội suy chất lượng cao
  3. Chạy YOLO-P2 custom trên crop upscaled → phát hiện bóng đèn đỏ/vàng/xanh
  4. HSV Fallback — quét màu trên không gian HSV (xem Section 4)
  5. Merge kết quả YOLO-P2 + HSV bằng WBF (IoU = 0.35)

Tầng 4 — OCR Nhận diện số đếm ngược

Với mỗi bóng đèn phát hiện, crop và chạy OCR pipeline (xem Section 5).

💡 Điểm quan trọng: Single-Pass Detection

Ban đầu hệ thống sử dụng Quadtree Spatial Slicing để chia nhỏ ảnh (3–5 lần suy luận). Chúng tôi đã loại bỏ hoàn toàn đệ quy và thay bằng 1 lượt suy luận duy nhất ở imgsz=1280. Kết quả: giảm latency ~65%, tăng confidence từ 0.20 → 0.63.

4 Phân Tích Màu HSV Thích Nghi

Ngoài YOLO-P2, hệ thống sử dụng phân tích màu HSV (Hue-Saturation-Value) như một fallback detector để bắt được các bóng đèn mà YOLO-P2 bỏ sót. HSV tách biệt thông tin màu sắc (Hue) khỏi độ sáng (Value), phù hợp với điều kiện ánh sáng thay đổi.

Bảng Ngưỡng HSV cho Detection

Màu Hue Min Hue Max Sat Min Val Min Ghi chú
Đỏ (1) 01250130 Dải đỏ thấp
Đỏ (2) 16518050130 Dải đỏ cao (wrap-around)
Vàng 133450130
Xanh lá 3511035120 ⚡ Mở rộng phủ cyan LED
⚡ Cải tiến quan trọng: Mở rộng ngưỡng xanh lá

Đèn LED xanh lá hiện đại tại Việt Nam phát xạ ở bước sóng 495–565 nm, tương đương Hue ~90–110 trong HSV. Ngưỡng cũ [36, 90] bỏ sót ~30% đèn xanh thực tế. Chúng tôi mở rộng lên [35, 110] để phủ được dải cyan LED. Kết quả: confidence đèn xanh đạt 90–97%.

Xử lý contour

  • Morphological Open + Close: kernel ELLIPSE 3×3 — loại nhiễu nhỏ và lấp đầy khe hở
  • Diện tích tối thiểu: 350 pixel (trên ảnh upscaled 4×)
  • Aspect ratio: 0.4 ≤ ar ≤ 2.5
  • Confidence: 0.5 + 0.5 × solidity (solidity = area / convex_hull_area)

5 Nhận Diện Số Đếm Ngược (OCR Pipeline)

Hệ thống đọc số đếm ngược trên đèn giao thông bằng pipeline 6 bước:

BướcXử lýMục đích
1 HSV Color Masking Tách pixel sáng (đỏ/vàng/xanh) ra khỏi nền đen của đèn LED. Sat ≥ 25, Val ≥ 80
2 Morphological Closing (3×3) Nối các đoạn đứt nét của chữ số LED 7-segment
3 Upscale 3× (INTER_CUBIC) Phóng to chữ số cho OCR dễ nhận diện
4 OTSU Thresholding Binary hóa: chữ số trắng trên nền đen
5 Padding 30px đen Tạo margin để OCR detector trigger chính xác
6 EasyOCR readtext allowlist="0123456789", conf ≥ 0.15 
# OCR Pipeline — Pseudocode
hsv_mask = color_mask(crop, red | yellow | green)
closed   = morphologyEx(hsv_mask, MORPH_CLOSE, kernel_3x3)
upscaled = resize(closed, fx=3.0, fy=3.0)
binary   = threshold(upscaled, 127, 255, THRESH_BINARY)
padded   = copyMakeBorder(binary, 30, 30, 30, 30, BLACK)
result   = easyocr.readtext(padded, allowlist="0123456789")

6 Bộ Lọc Biển Báo Ngữ Nghĩa

YOLOv8 pretrained trên COCO thường nhận nhầm biển báo giao thông (biển cấm tròn đỏ, biển tốc độ vuông) thành đèn giao thông. Chúng tôi xây dựng 2 bộ lọc ngữ nghĩa dựa trên hình học để loại bỏ false-positive:

Rule A — Tall-Pole Filter

Điều kiện: Nếu aspect_ratio (h/w) > 1.7 VÀ width < 150 px → loại bỏ.

Lý do: Đèn giao thông thật treo trên thanh ngang luôn có ar < 1.0 (nằm ngang). Đèn đơn dọc max ar ~1.5. Box rất cao hẹp (ar > 1.7) thường là cột biển báo xếp chồng (biển cấm + biển chỉ dẫn).

Ví dụ: Box 123×244 (ar=1.98) chứa biển cấm đỏ + biển chỉ dẫn → ĐÃ LOẠI ✓

Rule B — Square-Fill Filter

Điều kiện: Nếu box vuông (ar 0.65–1.55) VÀ 80 ≤ width ≤ 160 px VÀ bóng đèn con chiếm ≥ 75% diện tích box cha → loại bỏ.

Lý do: Biển báo tròn/vuông khi bị detect, HSV sẽ tìm thấy vùng màu lấp đầy gần hết box. Đèn giao thông thật có vỏ housing lớn hơn bóng đèn bên trong.

Ví dụ: Box 92×101 (ar=1.10), sub Red Light 88×87 (w_ratio=0.96, area_ratio=0.83) → ĐÃ LOẠI ✓

Post-Filter bổ sung

  • Ghost-box removal: Box không có sub-detection màu nào + confidence < 0.18 → loại (YOLO fire nhầm vào texture nền)
  • Sub-detection deduplication: Nếu 2 bóng đèn cùng class overlap IoU > 0.40 → giữ cái confidence cao nhất

10 Kết Luận & Hướng Phát Triển

Kết luận

Hệ thống SDO đã giải quyết thành công 3 thách thức chính trong nhận diện đèn giao thông:

✅ Thành tựu đạt được
  1. Single-Pass Detection ở imgsz=1280 — loại bỏ Quadtree, giảm latency 65%, tăng confidence đáng kể
  2. Adaptive HSV với dải cyan LED mở rộng — confidence đèn xanh đạt 90–97%, không còn bỏ sót đèn LED xanh lơ
  3. Semantic Sign Filter — zero false-positive biển báo giao thông nhờ 2 rules hình học + 2 post-filter
  4. OCR đếm ngược — đọc được số LED 7-segment với confidence 92%
  5. Kiến trúc Microservices — scalable, tách biệt inference/orchestration/UI

Hướng phát triển

1 Fine-tune trên dataset Việt Nam Gán nhãn 500–1000 ảnh đèn giao thông VN để train YOLO-P2 chuyên biệt hơn
